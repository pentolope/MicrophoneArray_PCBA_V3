# A/B benchmark: Board A baseline vs future Board B candidates

Board A is the authoritative, immutable `microphone_array_v2.kicad_pcb`
as committed (identified in `board_a_baseline.json` by SHA-256). It is
the baseline of the experiment and is never modified by it.

Board B is a future candidate generated by the improved workflow
(semantic floorplan -> placement constraints -> numerical placement
optimizer -> trial routing -> score -> perturb; see the toolkit's
docs/placement_routing.md). Candidates live under `boardB/` and are
comparison artifacts only until explicitly promoted by a human
decision; nothing here changes what the released board is.

## Reproducing the Board A baseline

    "C:/Program Files/KiCad/10.0/bin/python.exe" \
        tooling/PCB_AutoDesignAndTest/run.py extract \
        board/manifest.live.json \
        --out benchmark/board_a_baseline.json \
        --nets <see baseline file's own net list> \
        --copper "F.Cu=0.035,B.Cu=0.035,In1.Cu=0.0152,In2.Cu=0.0152" \
        --board-thickness 1.6 \
        --validation <a current validation.json attempt>

Copper thicknesses are the approved fabricator catalog's finished
values (1 oz external = 0.035 mm; 0.5 oz internal = 0.0152 mm). GND is
deliberately not in the net list: its copper is zone-dominated and the
extractor inventories track segments only - reporting a "length" for a
plane net would misrepresent it.

## Rules of the experiment

- Same product requirements as Board A: schematic/netlist, component
  set/BOM (unless a justified optimization changes it, recorded),
  board outline, microphone acoustic positions, host and mechanical
  interfaces, electrical requirements, fabrication constraints.
- Board A's internal placement is NOT the starting point of any
  candidate; copying it would defeat the experiment.
- Both boards are evaluated by the identical metric schema
  (`ab_metrics.schema.json`); a metric a backend cannot yet measure is
  reported as unmeasured, never fabricated.
